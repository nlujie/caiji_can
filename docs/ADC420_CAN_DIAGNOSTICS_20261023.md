# ADS1118 4-20mA / CAN采集重构说明（2026-10-23）

当前分支: `main_ADC_4_20mA_CAN_1023_0929`。

## 根因调查与修改

原程序读取ADS1118时把32位SPI配置回读不匹配直接视为硬件故障，并将当前值强制写成0xFFFF；同时把小于3.6mA的数据也写成0xFFFF，上位机只看到FF FF，不能区分断线、传感器低电流和MISO浮空。原ID 0x122数据最后4个字节被固定填入FF FF FF FF，无论传感器有没有接都一样。

### SPI重新设计
1. 保持硬件片选PB0/N_O1、PB1/N_O2、PB10/N_O3（三片共用SPI1）；N_O1经ISO7741，N_O2/N_O3经PC817。
2. STM32F103 SPI1：PA5=SCK、PA6=MISO、PA7=MOSI，CPOL=0、CPHA=1，分频64（若APB2=72MHz则约1.125MHz）。手册PGA=±2.048V，860SPS。
3. 将采样事务拆开：**16bit写入SS=1、单次转换配置 -> 4ms等待 -> 16bit发送NOP 0x0000并读取转换结果**，避免读数据时再次写入转换配置。
4. 再单独进行32bit配置回读诊断；若回读不符但有采样，返回可观测的原始值并标记状态4（不应作为可靠的闭环控制依据）；SPI数据通路超时或回显+数据同时固定为0xFFFF/0则返回故障状态1。
5. Keil Watch增加`ads1118_drdy_before_read[0..2]`，代表每个芯片读取前DOUT/DRDY是否观察到低电平（1=低）。

### 采集换算
原理图4–20mA输入经过100Ω(0.1%)采样电阻、LMV324缓冲：
`V = ADC_signed * 2.048 / 32768`，`I_mA = V*1000/100`。
若SPI事务成功，无论电流是否处于4–20mA，**CAN数据都发送实际换算值**（单位0.01mA）；断线约0mA则上传0，并通过诊断状态2标注，不再填0xFFFF。只有确认SPI采集失败才在电流帧上报0xFFFF。
状态0正常、1 SPI通讯故障、2欠量程（包括断线）、3超量程、4 SPI配置回显异常（电流数值仅供诊断）。

### CAN报文（500kbps、标准11位ID、小端uint16、目标200ms每轮）
| ID | 数据 | 说明 |
|---|---|---|
| 0x120 | ADC_2~ADC_5, each uint16 | 0.01mA |
| 0x121 | ADC_6~ADC_9 | 0.01mA |
| 0x122 | ADC_10、ADC_11、0、0 | 去除固定的FF FF FF FF |
| 0x130 | ADC_2~ADC_5原始ADC码 | 每路uint16，小端 |
| 0x131 | ADC_6~ADC_9原始ADC码 | 同上 |
| 0x132 | ADC_10、ADC_11、0、0 | 同上 |
| 0x133 | ADC_2~ADC_9状态 | 每路1字节，0/1/2/3/4 |
| 0x134 | 字节0/1=ADC_10/11状态, 2/3/4=芯片1/2/3传输失败次数低8位, 5=轮次, 6/7=芯片1/3配置回显异常次数低8位 | 诊断帧 |

`ADC_2`数组下标0，依次到`ADC_11`下标9。
P10/P11属于N_O2，P1/P2/P4/P5属于N_O1，P9/P7/P8/P6属于N_O3（顺序见`Hardware/func.c`映射）。
`ADC_0、ADC_1`为执行器反馈，未纳入10路电流上传。

### Keil Watch
- `adc420_raw_samples[0..9]` 实际收到的原始16位码
- `adc420_voltage_v[0..9]` 输入电压(V)
- `adc420_current_ma[0..9]` 计算电流(mA)
- `adc420_current_centi_ma[0..9]` CAN整数(0.01mA)
- `adc420_status[0..9]` 电流/通讯状态
- `adc420_config_echo[0..9]` 32位回显帧中的配置字
- `ads1118_drdy_before_read[0..2]` 读取前DRDY低电平观测
- `adc420_spi_error_count[0..2]` 芯片1/2/3 SPI硬故障累计
- `adc420_echo_mismatch_count[0..2]` 配置回显不匹配累计
- `adc420_can_tx_ok_count` / `adc420_can_tx_error_count` CAN发送状态累计

### 验证
接入12.00mA标准信号，100Ω端预期1.200V、约19200原始码、`adc420_current_centi_ma`约1200，CAN字节`B0 04`。4mA对应6400、400、`90 01`，20mA对应32000、2000、`D0 07`。

如果0x130~0x132一直全FFFF且0x133状态1，说明SPI硬件连接/隔离/电源仍未成功，继续测D3.3V、A3.3V、U15 ISO7741 MISO，以及PB0、PB1、PB10有效片选。没有传感器接入时电流约0mA，0x120数据应为00 00且0x133状态2。
